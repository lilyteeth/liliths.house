##
## So you Want to Multiplex
## ========================
## (or maybe you just want tabs)
##
## tmux can help! tmux is essentially just a terminal emulator that runs in a
## terminal. this file is a tmux configuration, which by default lives in
## ~/.tmux.conf (pwz put me there >_<)
##
## to start tmux, run `tmux new-session -s <name>`... or just `tmux`
## did it work? congrats! you're in a terminal multiplexing session :D
##
## you can invoke tmux commands within a session by running
## `tmux <command> [<args>]`, for example try running this:
##
##     tmux split-window # or just `tmux sp`
##
## tmux also lets you bind keys to commands, with this config (mooostly
## defaults, however these binds are not default):
##
## * Ctrl+b / does `split-window -v`
## * Ctrl+b ' does `split-window -h`
## 
## most keys in tmux are bound behind a prefix key, and the default prefix is
## Ctrl+B, or C-b in tmux-speak. bindings are highly customizable, so.. please
## don't worry too much if you don't like how it feels yet! for now, in in a new
## terminal, not in tmux, try:
##
##     tmux attach-client # or `tmux a`
##
## and try typing something in. it should appear in both tmux clients!  try
## detaching now, by running (this time in one of the tmux terminals):
##
##     tmux detach-client # or `tmux d`, or press C-b d
## 
## you can even detach all clients and the tmux session will stick around
## waiting to be attached to again, which feels like having pocket dimension
## terminals :3
##
## what you might call tabs tmux calls windows, splits within tabs it calls panes.
## so to make a "new tab", run (in an attached client)
##
##     tmux new-window # or `tmux neww`, or press C-b c
##     # (C-b n is bound to "next-window")
##
## windows will close automatically when you exit the last terminal in it, which
## is the main way i use it. (but if for some reason you need it, tmux
## kill-window exists)
##
## Ctrl+B can feel a little ungainly to press all the time but its actually
## pretty hard to find keys which don't overlap with keys used by other terminal
## programs; you *can* use a nicer prefix key that conflicts (such as Escape)
## and bind for example Escape Escape to passthrough (with the send-prefix
## command!) but,, thats up to you.
##
## also man 1 tmux is your friend :3 (fr i learned sm looking stuff up while
##  writing this..)
##
## good luck! <3

### options
##  =======

## enables resizing panes by click+dragging on borders
set -g mouse on
## enables sending the name of the running command to the containing
## terminal emulator so it can be set as the the X11 or wayland window title
set-option -g set-titles on
## add a prefix to set-titles
set-option -g set-titles-string "tmux: #W"

## show an indicator when a program emits a bell for attention, as well as pass
## it on to the containing terminal
set-option -g visual-bell both

## to be honest i did not take good notes on this when i was configuring it
## years ago.. but i was trying to get vim to display in full color within
## tmux.. and it does work...
set-option -g default-terminal "xterm-256color"
set-option -ga terminal-overrides ",xterm-256color:Tc"

## themeing! yea :3
## this makes the status bar not have a background (bg=default)
set -g status-style fg=color4,bg=default
## this makes the active window in the status does have a background
set -g window-status-current-style fg=color0,bg=color4
## border color tweaks that work well with my terminal theme
set -g pane-active-border-style fg=magenta

## timeout in milliseconds to let you press <prefix> key key key
## without having to repress <prefix>.. i made mine pretty short 
set -g repeat-time 200

## copy these environment variables when attaching
set-option -ga update-environment ' DBUS_SESSION_BUS_ADDRESS DISPLAY'

## use built-in vi-like binds in copy-mode
set-option -g mode-keys vi

## the bindings below are not particuarly well thought out but i do find them a
## little more ergonomic than the defaults
bind-key -r -T prefix $up select-pane -U
bind-key -r -T prefix $down select-pane -D
bind-key -r -T prefix $left select-pane -L
bind-key -r -T prefix $right select-pane -R
bind-key -T prefix w last-pane
bind-key -T prefix b last-window

bind-key -r -T prefix M-$up resize-pane -U 5
bind-key -r -T prefix M-$down resize-pane -D 5
bind-key -r -T prefix M-$left resize-pane -L 5
bind-key -r -T prefix M-$right resize-pane -R 5

bind-key -r -T prefix C-$left resize-pane -L
bind-key -r -T prefix C-$right resize-pane -R
